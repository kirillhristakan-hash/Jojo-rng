# JOJO RNG — Stand Arrow Online

Фанатская RNG-игра по мотивам JoJo's Bizarre Adventure. Крутишь Стрелу, собираешь стенды, ловишь мутации, проходишь арену, перерождаешься через Made in Heaven — и всё это с онлайн-комнатами, чатом, дуэлями и рейдом.

Полностью статический проект: **HTML + CSS + JS, без сборки и без сервера**. Поэтому он идеально живёт на GitHub Pages.

---

## Что внутри

**Контент**
- 137 сущностей в 12 рангах: от «Прохожего» (1/1.2) до «Апофеоза ДжоДжо» (1/7 700 000).
- 18 мутаций с множителями от ×1.25 до ×45 («Заряжен Хамоном» → «Сделано в Раю»).
- Индекс с прогрессом коллекции и счётчиком дублей.
- 32 достижения, ежедневные задания (3 в сутки), 12 боссов арены + бесконечный режим.
- Престиж «Made in Heaven» и Древо Небес с постоянными бонусами.

**Механики**
- Ролл с кулдауном, мульти-ролл (×5 и выше), авто-спин, турбо-режим.
- Экономика Спина: улучшения удачи, скорости, дохода, шанса мутации, гарантии минимального ранга.
- Арена: пошаговый бой, криты, стойкость, растущие награды.
- Сохранение в localStorage + экспорт/импорт строкой (перенос прогресса между устройствами).

**Онлайн (без сервера)**
- Комнаты по 5-символьному коду, вход по коду.
- Список игроков с их лучшими стендами, чат, общая лента роллов.
- Дуэли 1-на-1 (3 схватки, сравнение силы с элементом случайности).
- Совместный рейд на босса: общее ХП, вклад каждого игрока, награда всем при убийстве.
- Работает на WebRTC (PeerJS): хост — это браузер игрока, данные идут напрямую между игроками.

## Деплой на GitHub Pages (5 минут)

1. Создай новый репозиторий на GitHub, например `jojo-rng` (Public).
2. Загрузи в корень репозитория **все файлы из этой папки**:
   ```
   index.html
   style.css
   data.js
   game.js
   net.js
   ui.js
   README.md
   ```
   Через веб-интерфейс: `Add file → Upload files` → перетащи файлы → `Commit changes`.
3. Открой `Settings → Pages`.
4. В блоке **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)**
   - Нажми **Save**.
5. Через 30–60 секунд сайт будет доступен по адресу:
   ```
   https://<твой-ник>.github.io/jojo-rng/
   ```

Важно: `index.html` должен лежать **в корне** репозитория (или в папке, которую ты выбрал как root для Pages), иначе главная страница не откроется.

### Обновление
Меняешь файлы → коммитишь в ту же ветку → Pages пересобирается сам. Иногда нужно обновить страницу с `Ctrl+Shift+R`, чтобы сбросить кэш.

### Свой домен
`Settings → Pages → Custom domain` → вписать домен → добавить CNAME-запись у регистратора.

## Локальный запуск

Просто открой `index.html` двойным кликом — игра запустится без сервера (все скрипты классические, не ES-модули).

Если хочется проверить именно как на Pages:

```bash
cd jojo-rng
python3 -m http.server 8080
```

и открой `http://localhost:8080`.

## Как играть

| Действие | Что делает |
|---|---|
| **SPIN** | Один ролл. Пробел тоже работает. |
| **×N** | Мульти-ролл, показывает лучший результат из пачки. |
| **АВТО** | Авто-спин (нужно купить «Авто-Спин» в магазине). |
| **ТУРБО** | Отключает анимацию для обычных роллов. |
| **Индекс** | Коллекция: серые карточки — ещё не найдены. |
| **Магазин** | Улучшения за Спин + Древо Небес за Наследие. |
| **Арена** | Бои с боссами, достижения, статистика. |
| **Онлайн** | Комнаты, чат, дуэли, рейд. |

**Совет по прогрессу:** первые престижи делай, как только появляется кнопка «ПЕРЕРОЖДЕНИЕ» — каждый престиж даёт +25% удачи и +50% дохода навсегда, а индекс и достижения не сбрасываются. Ветку «Наследие Джостаров» в Древе Небес качай первой.

## Онлайн: как это устроено и что важно знать

- Хост создаёт комнату → получает код → остальные вводят код.
- Хост — обычный браузер: пока он на странице, комната жива. Ушёл хост — комната закрылась.
- Сигнализация идёт через публичный PeerJS Cloud (`0.peerjs.com`), сами данные — напрямую через WebRTC.
- Иногда публичный сигнальный сервер перегружен: если комната не создаётся, подожди 10–20 секунд и попробуй снова.
- Некоторые корпоративные/школьные сети блокируют WebRTC — там онлайн не заведётся, офлайн-режим продолжит работать.
- Дуэли и рейд считаются на клиентах (доверительная модель). Это casual-игра, античита нет.

## Структура файлов

```
index.html   — разметка всех экранов, оверлеи, подключение скриптов
style.css    — вся вёрстка, анимации, адаптив под мобильные
data.js      — контент: редкости, сущности, мутации, боссы, ачивки, задания, улучшения
game.js      — состояние, сохранения, RNG, экономика, арена, престиж, задания
net.js       — PeerJS: комнаты, чат, дуэли, рейд (звезда вокруг хоста)
ui.js        — рендер, звук (WebAudio-синтез), эффекты, обработчики
```

Внешние зависимости: только `peerjs` с unpkg (CDN). Иконки и звук — эмодзи и синтез, никаких ассетов.

## Технические детали

- Сохранение: `localStorage["jojorng.save.v2"]`, автосейв каждые 15 секунд и при уходе со страницы.
- Экспорт сохранения — Base64 от JSON (`Настройки → Сохранение`).
- Формула шансов: `weight_i × luck^(0.25 + (tier−2)×0.26)`; удача не влияет на низкие ранги, чтобы игра не ломалась.
- Сила стенда: `power_ранга × качество статов × мутация × бонусы престижа`.
- Мобильная вёрстка: safe-area, крупные тапы, `viewport-fit=cover`.
